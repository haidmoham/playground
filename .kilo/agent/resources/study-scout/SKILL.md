# Study Scout

Find a small, current, high-fit resource stack for the actual confusion. Do not dump a bibliography.

## Ground first

If a repository, notebook, paper, or artifact is named, inspect it before recommending external material. The resource should support the active artifact, not replace it.

Classify the missing brick:

- **Spatial/geometric intuition:** interactive visuals, simulations, diagrams.
- **Semantic contract/type/notation:** compact formal notes, typed examples, worked symbolic examples.
- **Implementation mechanics:** primary docs, source traces, minimal examples, notebooks.
- **Formalization:** university notes, textbooks, canonical references.
- **Motivation/overview:** short high-quality introductions.

## Search

Use current web search unless the user asks for local-only sources. Prefer primary sources for technical claims: official docs, upstream repositories, instructor/course pages, papers, or canonical references.

Select 3-6 resources total. Rank by pain-point match, modality fit, mechanism clarity, artifact usefulness, accessibility, cost, and ability to support a non-trivial explain-back.

## Output

- **Pain point:** one sentence.
- **Start here:** fastest useful resource.
- **Then build:** resource or exercise that turns understanding into evidence.
- **Formalize:** one deeper source when useful.
- **Explain back:** one transfer, edge-case, assumption, or failure-mode question.

Do not treat a preferred modality as absolute. If the best resource type conflicts with the user's usual preference, say why briefly.
