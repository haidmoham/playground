# Synthesize

Read-only by default. The ontology is evidence; synthesis is a hypothesis until accepted and curated.

## Modes

### Connect

For two named anchors:

1. Ground each anchor in its current repository or source when available.
2. Pull only the relevant ontology records.
3. Look for mechanism transfer, shared failure mode, inverted constraint, or structural analogy.
4. Produce 1-3 bridges. Mark analogy-only bridges explicitly.

### Emerge

For an open pattern search:

1. Work from compact records first.
2. Look for a mechanism supported across distinct domains, not repeated wording.
3. Confirm the pattern against the underlying records and their provenance.
4. Surface the strongest 1-3 patterns with supporting record ids.

## Graph use

If an optional derived graph exists, it may propose candidate neighborhoods. It does not establish truth. Confirm every useful graph path against canonical ontology records.

## Promotion

Do not write a new record automatically. If a synthesis survives scrutiny and changes decisions across domains, hand it to `librarian` for the normal admission gate.
