# Codify

Promote confirmed knowledge. Keep transient context where it is.

## Route

1. Confirm that the item is a preference, repeated correction, workflow rule, or standing instruction. Ask for confirmation when the item is tentative or appears once.
2. Choose the narrowest canonical home:
   - Put project-local rules in that project's source, instructions, or documentation.
   - Send cross-domain or core knowledge to the Poneglyph librarian.
   - Change a canonical skill source only when the item changes agent behavior.
3. Check the selected home for an existing rule. Update it instead of creating a duplicate.
4. Make the smallest durable change. Preserve source context and scope.

## Reject

Do not codify:

- raw transcripts or conversation logs;
- task queues, reminders, or temporary plans;
- duplicate documents or copies of project-local rules;
- retired pre-slim-brain paths;
- automatic broad system changes.

Do not promote a local rule to Poneglyph without cross-domain value. Do not turn a single request into a standing instruction.

## Report

State the confirmed item, its canonical home, the change made, and any reason to keep it out of durable storage.
